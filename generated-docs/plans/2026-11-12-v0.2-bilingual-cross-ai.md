# 学习伙伴 0.2 实施计划（2026-11-12）

**目标：** 把学习伙伴改为中英双版、按能力分层适配不同 AI，并让每日回顾由脚本执行。

**做法：** 脚本以英文版目录为唯一来源并复制到中文版；规则按主题拆到六份 reference；数据库加两张表承载回顾；交接文件和会话摘要作为无工具环境的接口。

**技术：** Python 3.11+ 标准库、SQLite、unittest；Windows 需 tzdata。

**设计：** [0.2 设计](../designs/2026-11-12-v0.2-bilingual-cross-ai-design.md)

**执行方式：** 用户已选择在同一会话内直接实施，本计划与实现在同一个 PR 中提交，各任务的测试与代码一并完成。

## 全局约束

- 间隔固定为 1、3、7、14、30 天；一批固定四轮。
- 掌握证据引文去除标点后至少 8 个字符。
- 启动提示词不超过 6000 字符。
- 0.1 的数据库、配置和导出目录无需手工迁移，且不丢失手写文件。
- 规则正文不出现厂商名称。
- 仅使用合成测试数据。

## 审查重点

1. 用户的 `state_dir` 里已有手写 `recurring-questions.md`：导出不得覆盖。测试 `test_review_files_are_generated_and_hand_written_list_is_set_aside`。
2. 0.1 数据库没有 `course_id` 列：任何命令打开即迁移。测试 `test_database_from_0_1_is_migrated_in_place`。
3. 同一份摘要被导入两次：事件、疑问出现次数和回顾进度都不得重复。测试 `test_digest_becomes_events_questions_and_reviews_and_replay_is_harmless`。
4. 摘要中途不合法：不得留下已导入未提交的轮次。测试 `test_rejected_digest_writes_nothing`。
5. 0.1 配置没有 `language`：导出保持中文。测试 `test_new_profile_defaults_to_english_and_legacy_config_stays_chinese`。

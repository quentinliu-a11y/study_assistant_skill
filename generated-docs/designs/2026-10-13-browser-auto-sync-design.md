# 浏览器学习自动记录：接入设计

日期：2026-10-13。状态：待用户审阅；尚未实现。

## 已确认目标

继续在 Chrome / Edge 中使用 ChatGPT，按课程记录学习。首次使用填写专业和本科／研究生阶段；每次学习确认一次。自动生成摘要并保存，用户已选择单独计费的 OpenAI API，由助手选择兼顾质量和成本的模型。现有总 Skill、课程知识库、SQLite 和逐日日志继续使用。公共代码发布到现有仓库，个人内容不公开。

## 方案选择

推荐：Manifest V3 扩展通过 Native Messaging 与本机 Python 程序通信。本机程序持久化任务、调用 OpenAI、校验摘要并导出 Markdown。不开放本地 HTTP 端口。扩展用持久队列与确认回执恢复断线，后台程序通过数据库锁保证单一任务领取。

备选一：localhost HTTP 服务，调试方便，但需要额外管理服务启动、认证和端口。备选二：云端服务，可在电脑离线后继续处理已上传的数据，但增加部署、账户和云端个人资料管理。本阶段采用推荐方案。

浏览器开启时由扩展保持本机连接并唤醒处理；关闭后不承诺后台继续运行。未完成任务恢复后继续。暂停后停止新采集及新模型调用；已发送的请求可能仍计费，其返回结果先保留待处理，不擅自继续发布。

## 用户流程

1. 安装扩展与本机组件。设置页填写缺失的专业、学习阶段、时区；本机配置 API 密钥。默认模型 gpt-5.4-mini，可修改。
2. 在课程聊天中点击“开始学习并记录”，选择或确认课程。能从页面确认 Project 时提供绑定建议；无法确认时使用当前聊天绑定，不猜测项目归属。
3. 页面显示本次计数、采集状态、待处理任务、最近保存时间、估算费用，以及暂停、立即更新、结束学习入口。
4. 满四轮有效学习问答自动总结；立即更新和结束学习提交不足四轮的余量。只有持久化成功才显示“已保存”。
5. 扩展可查看最新课程状态，并提供复制／下载供下一次网页学习使用。自动保存不等于 ChatGPT 自动读取本机文件；本阶段不自动发送消息或改写 Project Sources。

## 采集完整性与日期

仅采集开启记录后的当前聊天，不扫描其他聊天或后台历史。初次启用时可见旧消息只作为基线，不自动导入。保留公式原始 TeX；图片只记录存在，不声称已理解图片内容。

消息键使用页面提供的稳定聊天及消息 ID；无稳定 ID 时停止自动入库并提示，位置编号不能代替稳定 ID。问答配对需角色顺序清晰且回答结束信号明确；流式内容只存草稿。稳定窗口和结束信号组合检查，无法确认时等待或提示人工确认，不单凭固定延迟认定完成。

编辑／重生成保留版本和来源链，不覆盖已总结记录，也不算作新的四轮进度。发现已处理内容变化后进入待核对状态；本阶段不自动重写既有掌握判断。跨标签页去重，切换聊天时停止向旧聊天提交新页面内容。

现有 schema v1 要求可信原始时间。新增采集格式 v2 必须区分 source_time（可空）、first_observed_at、time_basis。无法获得原始时间的新消息按首次观察日期归档，日志显式写“采集日期，原始时间未知”；不将观察时间冒充原始时间。老 v1 输入和导出继续兼容；旧历史导入仍保留原始日期。

## 学习筛选和四轮机制

会话确认后先积累候选完整问答；纯界面操作不产生问答。每四个新候选由一次结构化分类调用判断 study/nonstudy/uncertain，依据专业、课程与学习意图，而不是单个术语。

非学习轮次标明原因后排除；uncertain 保留待用户归类，不进入掌握状态。满四个已分类 study 轮次才触发摘要。混入闲聊时继续等待下一组候选；“立即更新”会分类和处理余量。界面分别显示待分类数量和已确认学习数量，避免伪称精确即时识别。分类同样计入 API 费用。

## 摘要与课程更新

Responses API 使用严格 JSON Schema；store=false。输入仅包含该批原文、专业阶段、当前状态和相关课程知识点，不重复发送整本教材。模型不使用工具，不执行网页中的指令。

输出包含疑问、误区、解释状态、相关概念、用户作答证据和下次起点。调用现有来源、掌握证据及版本校验，失败不推进检查点。“懂了”和助手讲解不能作为独立掌握证据。新概念先进入带来源的候选集合；通用 Skill 规则和考试权重不由聊天自动改写。

## 本机通信与凭据

Native Messaging host 限定安装时确认的扩展 ID；只提供 profile、session、enqueue、status、flush、pause、state 等固定操作，拒绝任意路径与命令。扩展 worker 校验消息来源和载荷大小；内容脚本不直接调用本机程序。安装器默认当前用户注册，提供卸载和连接诊断。

API 密钥由本机进程读取 OPENAI_API_KEY，不写入扩展、仓库、普通日志或模型输入。仅发送选中学习会话的必要文本到官方 OpenAI API；原始教材不批量上传。没有密钥时队列可以持久保存，模型任务显示“待配置”，不得伪造成功。

## 任务、重试与费用

任务键由课程、会话、消息版本、操作、提示版本组成；摘要和处理检查点事务提交。缓存已收到且有效的 API 响应，本地提交失败时复用，避免重新付费。持久化任务领取和租约，崩溃后恢复；同课程顺序更新。

429 和明确可重试服务错误采用退避，最多三次；401、额度不足和配置错误暂停并提示。响应格式失败最多一次修复，计入预算。请求已发出但结果未知时不自动无限重发，保留“结果未知／可能已计费”，由用户选择重试。无法承诺 API exactly-once 计费。

默认应用内预算：每天 1 美元、每月 10 美元，可调。调用前按输入上界与最大输出预留，返回后用 usage 结算；结果未知保留预留。预算不足时停止付费任务但继续本地排队。预算只限制本程序，不限制同一 API 账户的其他应用。价格带核验日期，模型或价格变化需更新配置。

默认 gpt-5.4-mini，输入每百万 token 0.75 美元、输出 4.50 美元（2026-10-13 官方模型页）。例：8,000 输入＋2,000 输出约 0.015 美元，未计额外分类或重试。上下文超限不静默截断，拆分且保留来源或显示需处理状态。首次真实 API 冒烟测试使用合成问答并受应用预算控制。

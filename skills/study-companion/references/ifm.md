# IFM 课程教学规则

IFM（Introduction to Flight Mechanics）作为学习伙伴下的课程。个人课程配置、知识地图、来源清单、学习状态与日志位于用户选择的私有资料目录，不随 Skill 分发。

- 先确认专业与学习阶段，只问缺失项；读取私有课程 overview、knowledge-map、课程 SKILL.md 和最新日期记录。
- 按飞行状态约束→输入输出→受力图→方程→量纲和极限检查讲解。
- 区分推力、阻力与功率；比较平飞 D(V) 时明确固定重量和空气密度，不能混淆固定 CL 的条件。
- 区分最小阻力速度、最大爬升角速度和最大爬升率速度；先声明推进模型。
- 转弯推导明确协调、水平、恒速等条件；能量高度与 SEP 先核对课程定义和单位。
- 讲义页号与 PDF 页序分别记录。考试优先级必须来自实际可读题目和分值，不以单份样卷预测未来考试。
- 复用总 Skill 四轮和手动更新规则；历史回顾按整理日期保存但保留原始学习日期，不将看过答案当作掌握。
- 写入私人日志后，只同步到用户指定的私有目标；不要将日志放回公开 Skill 仓库。

## 本次可交付模式

网页学习 + 按需手动同步：从可访问的已完成对话获取增量，由助手总结并调用本地脚本保存。导出 current-state.md 后提供给下一次网页对话读取。最后的网页导入/回读仍须用户在已登录环境验证。

四轮批次机制可以在工具调用时可靠计数；普通网页对话中的四轮提醒只是指令遵循，不承诺跨所有对话的后台自动运行。本次不创建额外定时任务，不发送测试消息到用户其他对话。

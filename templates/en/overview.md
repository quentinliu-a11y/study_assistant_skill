# Course overview

Fill in when the course is set up: course name, course_id, major, study level, scope, and how much of the material has been read.

The source index lists, for each file: source_id, file name, version or SHA-256, whether it is readable, and page count. List lectures, textbook, tutorials, and teacher hints separately. Scanned material has to be checked as images. Mark missing content "not read", not "none".

This template is not a generated course. Until it is filled in, give no course-specific exam weights.

Course-specific rules (notation, common traps, the lecturer's definitions) can go in a separate rules file in the same folder. Progress, questions, and review history do not belong here; they are in the exported handoff.md and related files.
